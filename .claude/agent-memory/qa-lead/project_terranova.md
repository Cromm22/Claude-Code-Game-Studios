Terranova is a planetary survival game with ecological predator AI, built on Roblox Studio (Luau, --!strict). Testing framework is TestEZ. The project is in pre-production; GDDs are being authored and reviewed. The ecological disturbance GDD has completed two review rounds as of 2026-04-29.

**Why:** Needed to orient QA tooling and test evidence requirements to Roblox/Luau specifics (TestEZ, MicroProfiler, Knit RemoteSignal layer).

**How to apply:** All unit test evidence must be TestEZ-compatible. PERF-DEVICE ACs require a physical iPhone SE-class device and MicroProfiler — Studio simulator is not valid evidence.
