Active project: Terranova — first-person alien survival on an alien planet (Unity 6.3 LTS, C#, URP).

Core mechanic: Triple resource management (food/water/oxygen) + apex predator hunts along ecological disturbances the player creates.

Design stage as of 2026-04-22: Systems index complete (27 systems). Biome GDD is In Review (re-review pending). Item Database GDD skeleton created, in active design. Ecological Disturbance GDD is the highest-priority next design task (9 systems depend on it).

Item Database design session initiated 2026-04-22: Designing MVP item set (~10 craftable items, 3 tiers), 5 base structures, and knowledge gate system. Scanner/radar is explicitly NOT in MVP. No tutorial text — world teaches through consequence.

**Why:** Item Database is Foundation layer — must be complete before Crafting, Inventory, Resource Node, Base Building, and World Generation GDDs can be finalized.

**How to apply:** When working on Item Database, ensure all item names are specific (not generic), all gate conditions are implementable and testable, and all designs serve at least one of the 5 pillars.
