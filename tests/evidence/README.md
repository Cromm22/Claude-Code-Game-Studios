# Test Evidence

Ad-hoc screenshots and manual sign-off records captured while authoring or
running Visual/Feel and UI story tests (per `tests/README.md`'s Story Type →
Test Evidence table). Dated, gate-facing smoke-check reports belong in
`production/qa/`, not here — this directory is working evidence, not the
formal record.

Naming: `[system]-[short-description]-[date].png` (+ an optional `.md` note).
